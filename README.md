# Calc IDE для Android

Редактор и консоль для вашего языка. Интерфейс — на Python/Kivy, а сам компилятор (C++) собирается
в библиотеку `libcalccore.so` внутри того же APK. APK собирает GitHub Actions — ничего ставить на компьютер не нужно.

## Что где лежит

```
main.py                    приложение Kivy: редактор, кнопки, консоль, файловые окна
calc_bridge.py             мост к C++ через ctypes: рабочий поток, вывод, input, «Стоп»
session.py                 логика консоли (REPL, команды, модель вывода) — без Kivy
buildozer.spec             настройки сборки APK
fonts/JetBrainsMono-Regular.ttf   моноширинный шрифт с кириллицей (лицензия SIL OFL 1.1)
recipes/calccore/
    calc_core.cpp          ВЕСЬ компилятор + C-интерфейс (один файл)
    __init__.py            рецепт python-for-android: собирает calc_core.cpp под Android
tests/test_core.py         автотесты ядра и консоли (запускаются и на компьютере, и в GitHub)
.github/workflows/build-apk.yml   сборка APK в GitHub Actions
```

## Как загрузить на GitHub и получить APK

### Вариант 1: через сайт (без установки git)
1. На github.com: **New repository** → имя, например `calc-ide` → **Create repository** (галочки README/.gitignore не ставьте).
2. Распакуйте архив на компьютере. На странице пустого репозитория нажмите **uploading an existing file**.
3. Перетащите в окно **всё содержимое распакованной папки** (файлы и папки `fonts`, `recipes`, `tests`, `.github`).
   Важно: файл `buildozer.spec` должен лежать в **корне** репозитория, а не в подпапке.
4. Нажмите **Commit changes**.
5. Проверьте, что в репозитории есть путь `.github/workflows/build-apk.yml`. Папки с точкой в начале часто
   теряются при перетаскивании. Если её нет: **Add file → Create new file**, в поле имени введите
   `.github/workflows/build-apk.yml` (слэши создадут папки), вставьте содержимое файла из архива и нажмите **Commit**.

### Вариант 2: через git
```
cd calc-ide                       # распакованная папка
git init
git add .
git commit -m "Calc IDE"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/calc-ide.git
git push -u origin main
```

### Дальше
1. Откройте вкладку **Actions** репозитория. Сборка стартует сама после загрузки (если Actions выключены, нажмите
   зелёную кнопку согласия). Повторно запустить: Actions → «Сборка Android APK» → **Run workflow**.
2. Сначала выполняется задача **test-core** (около минуты) — автотесты компилятора. Затем **build-apk**:
   первый раз 30–60 минут (скачивается Android SDK/NDK и собираются Kivy и Python), потом быстрее из-за кэша.
3. Когда обе задачи зелёные, откройте последний запуск и внизу в разделе **Artifacts** скачайте `calc-ide-apk`
   (это zip с файлом `.apk` внутри).
4. Перенесите `.apk` на телефон и откройте его. Android попросит разрешить установку из этого источника.
   Это debug-сборка, подписанная отладочным ключом: годится для себя, но не для публикации в Google Play.

## Как пользоваться
- **Запуск** выполняет текст из редактора с чистой памятью, **Стоп** прерывает (в том числе ожидание ввода).
- Если программа дошла до `input`, консоль получает фокус и ждёт ответ — введите его и нажмите OK/Enter.
- В консоли работают команды языка и `help`, `vars`, `explain`, `quiet`, `opt`, `noopt`, `run`, `clear`.
- Строка кнопок над консолью вставляет `{ } ( ) " $ = ...` и Tab (4 пробела).
- При ошибке компиляции курсор встаёт на строку с ошибкой, текст ошибки — красным в консоли.
- «Копировать вывод» кладёт весь вывод консоли в буфер обмена.
- Файлы хранятся во внутренней папке приложения (при удалении приложения они пропадают). При сворачивании
  приложения текст сохраняется автоматически. `runF "имя.txt"` ищет файлы в этой же папке.

## Проверка на компьютере (необязательно)
```
python tests/test_core.py      # сам соберёт libcalccore.so компилятором g++ и прогонит 35 тестов
```
Запуск интерфейса на ПК: `pip install kivy`, затем `CALC_LIB=путь/к/libcalccore.so python main.py`.

## Если сборка упала
- Откройте упавший шаг в Actions и найдите **первую** строку с `ERROR`/`error:`; она важнее всего, что после неё.
- Ошибка при компиляции `calc_core.cpp` в рецепте — пришлите текст: возможно, нужна правка под NDK.
- Ошибки Cython/Kivy — в `buildozer.spec` можно закрепить версию python-for-android, например
  `p4a.branch = v2024.01.21`, и версию Kivy в `requirements`.
- На телефоне приложение сразу закрывается или пишет «Не удалось загрузить ядро»: подключите телефон и посмотрите
  `adb logcat -s python`, там будет причина (не найдена `libcalccore.so` для вашей архитектуры и т. п.).
